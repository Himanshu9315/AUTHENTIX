## Your entry code
Open My tickets, choose your ticket and press Show entry code. It is a QR code that changes every 30 seconds, so a screenshot stops working almost immediately. Keep the screen open when you reach the gate.

## At the gate
Staff scan your code. A green screen with your first name and last initial means you can go in. A red screen shows the reason, for example that the ticket was already used or the code expired.

## One entry per ticket
A ticket can be used once. If someone else enters with a copy of your code first, your own scan will show as already used, so please do not share your code.

## If your code will not scan
Make sure your phone has a connection so the code can refresh, turn the screen brightness up, and try again. If it still fails, ask gate staff for help.
