## What Verified entry means
Every ticket on Authentix is tied to one real, verified person. That is why you see a Verified entry badge on events. It stops bots and scalpers from buying up tickets and reselling them.

## Why we ask for Aadhaar
Verifying with an Aadhaar one-time code proves you are one real person, so each person can only have one account. In this demo only fictional test numbers are accepted.

## What we store
We never store your Aadhaar number. We keep a scrambled fingerprint of it, which can only be used to check that the same number isn't used twice, and the last four digits so you can recognise it.

## How to verify
Open Verify from your account, confirm your email first, then enter your Aadhaar number to receive a one-time code and type the code in.
