## One Aadhaar, one account
Each verified person can have exactly one Authentix account. This is the main rule that keeps tickets fair, because one person cannot create many accounts to buy more tickets.

## If it says the Aadhaar is already linked
That means another account has already been verified with the same Aadhaar. You cannot use it again on a new account. If you think this is a mistake, please contact support.

## Wrong codes
If you enter a wrong one-time code too many times, verification is paused for a short while. Wait and try again later.
